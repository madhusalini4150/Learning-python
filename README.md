#  Python Programming 
---

##  What is Python?

**Python** is a high-level, interpreted, and general-purpose programming language. It is known for its **simple syntax**, **readability**, and **versatility**. Python allows developers to write programs using fewer lines of code compared to many other languages.

* Created by **Guido van Rossum**
* Released in **1991**
* Open-source and free to use

---

##  Why Python?

Python is popular because:

1. Easy to learn and read (almost like English)
2. Works on multiple platforms (Windows, macOS, Linux)
3. Requires less code to perform tasks
4. Huge community support
5. Large collection of libraries and frameworks
6. Suitable for beginners and professionals

---

##  Applications of Python

Python is used in many real-world domains:

* Web Development (Django, Flask)
* Data Science & Data Analysis
* Machine Learning & AI
* Automation & Scripting
* Game Development
* Desktop Applications
* Cyber Security
* IoT & Embedded Systems

---

##  Disadvantages of Python

Although Python is powerful, it has some limitations:

* Slower execution compared to compiled languages like C/C++
* Not ideal for mobile app development
* Uses more memory
* Runtime errors (errors appear during execution)

---

##  First Python Program

```python
print("Hello, World!")
```

### Explanation:

* `print()` is a built-in function
* It displays output on the screen
* `"Hello, World!"` is a string (text)

---

##  Comments in Python

Comments are used to explain code and make it more readable.

### Single-line Comment:

```python
# This is a comment
```

### Multi-line Comment:

```python
"""
This is a
multi-line comment
"""
```

---

##  Input and Output in Python

### Taking Input:

```python
name = input("Enter your name: ")
```

### Displaying Output:

```python
print(name)
```

> Note: `input()` always returns a **string**.

---

##  Statements in Python

A **statement** is an instruction that Python executes.

Examples:

```python
x = 10
print(x)
```

---

##  Variables in Python

Variables are used to store data.

```python
age = 20
name = "Python"
```

Python is **dynamically typed**, so you don’t need to specify data types.

---

##  Rules for Variables

1. Must start with a letter (a-z, A-Z) or underscore (_)
2. Cannot start with a number
3. Can contain letters, numbers, and underscores
4. Cannot use keywords as variable names
5. Case-sensitive (`age` and `Age` are different)

---

##  Type Casting in Python

Type casting is converting one data type into another.

### Examples:

```python
x = "10"
y = int(x)
```

Common casting functions:

* `int()`
* `float()`
* `str()`

---

##  Type Casting with Variables

```python
a = 5
b = float(a)
c = str(a)
```

This helps when working with user input and calculations.
